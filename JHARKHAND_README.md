# CivicFix Jharkhand — Hackathon Configuration

This release is specifically configured for Jharkhand.

## Officially grounded state structure
The Government of Jharkhand lists 24 districts grouped into 5 divisions:
- Palamu: Palamu, Garhwa, Latehar
- North Chotanagpur: Chatra, Hazaribagh, Koderma, Giridih, Ramgarh, Bokaro, Dhanbad
- South Chotanagpur: Lohardaga, Gumla, Simdega, Ranchi, Khunti
- Kolhan: West Singhbhum, Saraikela-Kharsawan, East Singhbhum
- Santhal Pargana: Jamtara, Deoghar, Dumka, Pakur, Godda, Sahibganj

The official Urban Development & Housing/SUDA portal also distinguishes Municipal Corporations, Nagar Parishads and Nagar Panchayats.

## What CivicFix adds for the hackathon
Every complaint captures:
- Jharkhand district
- Local body type
- Locality/landmark
- GPS latitude/longitude
- Issue category
- Description
- Priority
- Department
- Status
- Duplicate count

## Important claim boundary
CivicFix is a hackathon prototype inspired by the Jharkhand civic/grievance ecosystem. It is NOT an official Government of Jharkhand portal and it does not automatically send complaints into the government's PGMS unless an authorized integration/API is later provided.
